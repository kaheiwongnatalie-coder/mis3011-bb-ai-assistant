# BB Companion · 课程安排与动态提醒

BB Companion 把 Blackboard 公告、作业截止时间、考试和学习准备时段放进同一张日历。当前测试版用仓库中的 `BB_Source_Feed` 模拟 Blackboard 接入。资料来自 2023 和 2024 年的课程包，按原学期和原日期使用。

## 给测试同学

[打开在线测试页](https://kaheiwongnatalie-coder.github.io/mis3011-bb-ai-assistant/#plan)

在线版无需安装或 API Key。页面会先载入历史课程样例，操作保存在当前浏览器。用「日历安排」查看月历，点任意日期进入该周。周历每两小时一格，准备时段仍按实际时长显示。

| 测试场景 | 怎么操作 | 预期结果 |
| --- | --- | --- |
| 月历与周历 | 在 2024 年 11 月点 11 月 2 日 | 打开包含 11 月 2 日的周历，并高亮该日。ECO3121 的 Problem Set 2 截止时间为 15:00 |
| 模拟公告更新 | 点「同步 BB 课程」→「载入改期前的资料」，查看 CSC1001 期中考试。再点「同步改期公告」 | 同一场考试从 11 月 1 日 19:00 改到 11 月 10 日 19:00，日历更新，旧提醒可在「动态提醒 → 已撤销」查看 |
| 完成任务 | 打开一项作业的详情，点「我已完成／提交」 | 任务显示已确认完成，相关准备时段和待发提醒更新 |
| 空闲时间与提醒 | 在日历调整「空闲设置」，再到「动态提醒」筛选类型 | 准备时段按设置重算，可查看截止、课程变更和安排提醒 |

反馈时请记录使用的是在线版还是本地版、所选日期、操作步骤、预期结果和实际结果。涉及课时或截止时间时，可以附上课程代码和公告标题。截图请遮住 API Key。

## 给后续使用者

本地学生版可以自动检查数据包的新公告和版本变化，也支持 AI 问答和自然语言排程。安装 Node.js 22 或更高版本后运行：

```sh
git clone --branch integration https://github.com/kaheiwongnatalie-coder/mis3011-bb-ai-assistant.git
cd mis3011-bb-ai-assistant
npm start
```

1. 打开 [本地学生版](http://127.0.0.1:4173/)，在右上角设置里连接模型。使用自己的 DeepSeek API Key，保存后点「测试连接」。模型调用按自己的账号计费，Key 保存在后台内存里。
2. 点击工作区日期，选择「2024 学期」，再在「课程同步」选择 CSC1001、ECO2021、ECO3121。开启自动同步后，后台处理已发布的公告，并补充作业页中有明确依据的截止日期。首次同步会分批处理，可在「课程同步」里看进度。
3. 从日历右侧打开 AI 助手，例如说「明晚没空，帮我重新排」。检查预览后点「应用到计划」。原文只有日期时，日历会标出日期并提示时刻待定。

在线版的「同步改期公告」是固定的历史样例，供同学重复测试。模型调用、整包自动同步和聊天排程由本地版运行。本版本的提醒在站内显示，学校实时 Blackboard 接口和真实提交回执尚未接入。

## 开发与交接

- `npm test` 运行回归测试。 `node scripts/mock-bb-demo.mjs` 在离线环境验证公告更新、任务去重、排程和旧提醒撤销。
- `node scripts/build-public.mjs --student-preview` 生成在线测试页，产物位于 `dist/student-preview/`。
- `BB_Source_Feed/` 是模拟输入。 `ai/` 负责资料理解和变更处理，`core/` 负责排程和提醒，`web/` 是学生端界面，`public/` 是 GitHub Pages 的浏览器运行层。
